## The owner's decisions, 2026-09-30

1. **Benchmark audio is kept for 12 months**, because a vendor changes its model and the set has to stay
   re-runnable to be comparable. **The transcript and the figures are kept after the audio is deleted,
   unless the speaker objects** — they are the record of how a recogniser was chosen. Written into
   `kit/consent-form.md`, and the placeholder is gone; what remains for the lawyer is whether it is
   expressible as drafted.
2. **The pre-screen's control is two ElevenLabs voice groups, not a second vendor.** ADR-0020 §2 asks
   for at least two TTS sources so that no recogniser is judged chiefly on its own vendor's audio. With
   one TTS account the set holds two Nigerian-accented voices and two general-accent voices from the same
   vendor, which measures the accent delta with synthesis artefacts held constant — a better control for
   *accent*, a worse one for *vendor*. **A second TTS vendor is owed before any provider is eliminated on
   synthetic evidence**, and the run's own notes say so.
3. **Deepgram is not gated on their written answer** (decided while building; the draft kit had blocked
   it). The opt-out is a parameter we send on **every** request and a test asserts that no request can be
   built without it, so their default enrolment governs only requests that omit it — of which there are
   none. The written answer is still owed for the subprocessor file, and it is a record-keeping question
   rather than a condition on any clip.

## Five things in the code that are decisions, not implementation details

**A rate is a (provider, model, path) with a billing *basis*.** Deepgram bills minutes of audio;
AssemblyAI's streaming product bills minutes the socket was open. An interview is mostly silence while the
candidate thinks, so one read as the other is about threefold wrong in the direction that flatters us —
`stt_cost_micro_usd` raises rather than guessing. It also makes the agent closing its socket an
operational rule rather than tidiness.

**What keeps candidate audio out of a vendor's training set is a parameter or a base URL.**
`mip_opt_out=true` on every Deepgram request; AssemblyAI's **EU host**, which is the mechanism and not a
latency preference; `use_disable_llm_corrections=true` for Intron, whose transcripts are otherwise
rewritten by a language model — a benchmark confound, and a hallucination in a report that quotes the
candidate. ElevenLabs has no such lever on a self-serve plan, so it is a **declared gap**, and a test
asserts every vendor declares one or the other.

**The report refuses to pool synthetic clips with real ones.** `refuse_mixed` raises rather than warning,
because a warning above a number is read once and the number is quoted for ever — which is very nearly
what happened to M4's fairness figure.

**Two refusals guard a free tier.** An unpriced provider does not run (`--allow-unpriced` turns every cost
figure into a floor), and `--dry-run` prices in **units against the allowance**: "6,184 of 30,000
characters (20.6%)" is what stops a run on a free tier, where "$0.25" stops nothing. ElevenLabs' allowance
is recorded as the **smaller** of their two published figures, for the same reason a billed second rounds
up.

**A draft reference is not a measurement.** ADR-0020 §4 wants a person to have listened to every clip,
because two recognisers that mishear an accent the same way **agree**. `--allow-draft` exists and stamps
the report as agreement between machines rather than accuracy.

## The normalizer, and the bug worth remembering

Word error rate is a function of what counts as the same word, so there is one normalizer with tests and
the transcription convention is written to match it. Its first version **corrupted its own inputs**: a
plain substring alias replace turned "requests" into "requestypescript" (`ts` → `typescript`) and cascaded
"postgres" → "postgresql" → "postgresqlsql". It was caught by printing eight sentences through it before
anything depended on the output. Aliases are word-boundary regexes now and the test names the bug.

Two gaps the recording-kit draft found in it, both fixed: bracketed markers (`[unintelligible]`,
`(laughs)`) are dropped, or each one is a free error against a recogniser that had nothing to write down;
and integers below 1,000 are written as words on both sides, so `80` and `eighty` compare equal. Above 999
it does not and cannot — "2026" is two different sentences — so the convention carries that as a rule for
people.

**`--smoke` is a real regression lock.** It scores a set it generates for itself, and the figures are
exact: 0%, 27.3%, 9.1%, pooled 12.5%, term error 20%, fillers 0%. The three hypotheses are deliberate
perturbations of their own references, so those numbers move only if the normalizer or the alignment moves.
A stand-in returning something unrelated would score ~100% and prove only that the pipeline runs.

## The recording kit, and what only the owner can fill

`evals/stt_benchmark/kit/` — drafted, then checked by hand against `docs/privacy/subprocessors.md`:

- **`recording-script.md`** — 12 read sentences dense in real glossary terms (Part A's text *is* the
  reference transcript, and the synthetic set uses the same sentences so the two are comparable), 6 spoken
  prompts in the register of our own question banks with one inviting Pidgin, and a spoken conditions note.
- **`consent-form.md`** — one page, plain language, for somebody with no account. **Marked at the top as a
  draft nobody may sign until a lawyer familiar with the NDPA 2023 has reviewed it**, with a "left for the
  lawyer" list rather than guesses.
- **`phone-instructions.md`** — the phone's own recorder rather than a WhatsApp voice note, because we
  re-encode to the product's codec ourselves; a 30-second test-and-listen step, one file per part.
- **`transcription-convention.md`** — the mechanical rules WER depends on, a pinned Pidgin orthography,
  and why the choice matters less than having one.

**Placeholders only the owner can fill**: legal entity name and registration number, privacy contact
email, postal address, the upload link, and the payment amount (or "none").

**And the gate**: no recording is made until a lawyer has reviewed the form (ADR-0020 §8).

## What phase 2 did not do

- **No second TTS vendor**, so the synthetic control is within one vendor (decision 2 above).
- **No real recordings**, and none may be made until the consent form is reviewed.
- **No streaming adapters.** These four are batch, deliberately: the live path is LiveKit's plugin with
  our key, wrapped for provider selection and `AiCallRecord` reporting (ADR-0019 §2). That wrapper is
  phase 3's, and phase 3 owes ADR-0019 two amendments already recorded in `tasks/todo.md` — the barge-in
  rule for a probe the candidate did not hear, and this batch/streaming split.
- **`INTERVIEW_LLM_TIMEOUT_S` is still 45 s**, a text-mode number that phase 3 has to replace.
