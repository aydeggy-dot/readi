## Decisions and deviations from the plan
- **Versions stepped back** under the maturity rule or for compatibility (details in ADR-0001): TypeScript
  6.0 (not 7), ESLint 9.39 (not 10), NestJS 11 (not 12), Vitest 4.1 (not 5), Prisma 7.10 (not 8 RC),
  Turborepo 2.10 (not 2.11).
- **MinIO → SeaweedFS** for local S3 after a side-by-side test (ADR-0001). Port 19001 (planned MinIO console)
  is unused.
- **Serwist works with Turbopack** (`@serwist/turbopack`); no webpack fallback (kickoff #22 closed).
- **Top-level contracts have no root `.meta({ id })`** (nestjs-zod 5.5 limitation, found via an OpenAPI test).
- **Client bundle:** landing page initial JS ≈ 180 KB gzip (framework baseline). Zod was removed from browser
  code (−85 KB); SW precache limited to the offline page (was 1.8 MB).
- **No OpenAPI-to-client generation yet** (`packages/api-client` placeholder); the web app validates API
  responses with `@readi/shared-types`.
- **No Playwright yet** — first e2e flow arrives in M1.

## Known issues / notes
- Starlette's TestClient emits an `anyio` deprecation warning (third-party; harmless).
- Prisma CLI prints an "update available" box pointing at the 8.0 RC; set `PRISMA_HIDE_UPDATE_MESSAGE=1` to
  silence it (CI does).
- LiveKit UDP from a Windows browser into WSL (NAT networking) is not forwarded; expect ICE-TCP locally (M5).
